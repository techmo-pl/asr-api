# Changelog of ASR API

## [1.1.1] - 2026-03-22

### Changed

- Minor documentation updates.


## [1.1.0] - 2024-04-25

### Added

- _techmo.asr.api.v1p1_ package extending _techmo.asr.api.v1_ with hold response functionality.
- Documentation reference for _techmo.asr.api.v1p1_ (autogenerated).


## [1.0.0] - 2024-01-12

### Added

- _google.rpc_ package with _status_ proto (copied from [googleapis@3daf3792](https://github.com/googleapis/googleapis/blob/3daf3792860423f9b7aad71083ee729d368dd241/google/rpc/status.proto)).
- _techmo.api_ package.
- _techmo.asr.api.dictation_ package (legacy _google.cloud.speech.v1_).
- _techmo.asr.api.v1_ package.
- Documentation references for _techmo.api_, _techmo.asr.api.dictation_, and _techmo.asr.api.v1_ (autogenerated).
- Script to generate documentation.
- Script to compile proto.
